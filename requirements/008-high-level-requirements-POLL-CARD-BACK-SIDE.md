Start a new spec for these requirements called 008-POLL-CARD-BACK-SIDE  
There is a bug on the backside of the Poll Card (the voting side).
The screenshot in "./designDocs/poll-card-back-side-bug.jpg" shows how the height of the Choices on the backside is much less than the frontside.
Please make the frontside and the backside choices area the same.

Also, add the "# participants voted" label to the backside, same as the frontside.
And then make the footer on both sides take the same space. In this case, the backside is preferable since the padding under the buttons is less. Make the width of the "Vote" button on the front, the same width as the "Submit Vote" button.
Finally, make the "Poll Closed" text with the same grey style as the "# particpants voted" text.
