Create a new spec 005 for these requirements.

All these requirements are all applicable to the /admin page.

The "Duplicate Poll" functionality should find a unique title for the new poll by starting with the title of the original poll being copied and appending " Copy". If that title isn't unique across all polls (even archived poll and closed polls) then a SPACE and a number starting at 1 is appended until a unique title is found. 

The links in the Action column needs to be moved to a menu in the Actions column that is made available by clicking a standard 'three dot' menu icon. This will allow many other Admin actions on a Poll without making the list crowded and too busy. A screenshot example is seen in "./designDocs/actionsMenu.jpg" (the screenshot is just for design reference, the actual menu items are the 4 Action links that currently exist: "Edit Poll", "Duplicate Poll", "Copy Poll Link", "View Results Admin-mode".
If you think a three line "hamburger menu" is more appropriate, please use that.

The header must be exactly as on the home page. In fact, every page on the site must have the same header.
